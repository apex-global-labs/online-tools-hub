Privacy Policy

Last updated: 31 October 2026. This policy explains the data flows in the current ToolNest website. It may be updated when tools or providers change.

Information you enter into tools

Most ToolNest tools process text and files in your browser. ToolNest does not operate an application backend that receives or stores those inputs. Your browser and device may still store information temporarily while a page is open or while you use browser features such as downloads.

Features that contact third parties

  • URL Shortener: the destination URL you submit is sent over HTTPS to Spoo.me to create a short link. The third-party provider processes that request under its own terms and privacy practices.
  • IP Address Finder & Lookup: the IP address you ask to look up is sent to the ipwho.is service for lookup information. Results such as city or network location are approximate.
  • Currency converter: the selected currency code is used to request exchange-rate data from open.er-api.com. Rates are indicative and may not match a live transaction.

Libraries and hosting

The website is hosted by GitHub Pages. The main application also loads some browser libraries and styling resources from public CDNs, including Tailwind CSS, unpkg and cdnjs. Those providers receive normal network requests from your browser and apply their own policies. GitHub and network providers may process technical request information such as IP address, browser details and requested resources.

Browser storage and clipboard

ToolNest saves your light/dark theme preference in your browser's local storage. Copy buttons use the browser clipboard only after you choose a copy action and the browser permits it. File selection and downloads are handled by your browser.

Accounts, advertising and analytics

ToolNest does not require an account. The current application does not include an account system or a ToolNest server-side database for tool inputs. This policy does not make claims about logs or data practices of GitHub Pages, CDNs or external API providers. Review their policies separately.

Children and sensitive information

Do not enter passwords, private keys, confidential documents or other sensitive information into online tools unless you understand the relevant data flow. In particular, remember that the third-party features listed above send request data to those providers.

Policy changes and contact

When tool behavior or providers change, this page may be revised. To report a privacy concern, use the public GitHub issue tracker; do not include sensitive personal information in a public issue.
