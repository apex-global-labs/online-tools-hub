Contact ToolNest

For bug reports, accessibility feedback or feature suggestions, use the ToolNest GitHub issue tracker.

Before submitting

  • Describe which tool and page you were using.
  • Include the steps that reproduce the problem and the browser/device type if relevant.
  • Do not post passwords, private documents, personal information or other sensitive data. GitHub issues may be publicly visible.

There is no public support email address listed for this project. The issue tracker is the published contact route.
