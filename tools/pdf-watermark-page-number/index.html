PDF Watermark & Page Number

Add a custom text watermark, optional logo and page numbers to PDF files. Adjust color, opacity, size, placement and page range with local browser processing.

Open PDF Watermark & Page Number →

How to Use PDF Watermark & Page Number

  1. Upload a PDF file.
  2. Enter watermark text and choose its color, opacity, size and style.
  3. Optionally add page numbers, choose their position, or upload a small PNG/JPG logo.
  4. Choose Apply to PDF, review the preview and download the updated document.

Key Features

  • Diagonal or centered text watermark with adjustable color, size and opacity.
  • Optional PNG/JPG logo overlay.
  • Optional page numbers with a starting number and left, center or right alignment.
  • Apply changes to all pages or a selected page range.
  • Watermark text is rendered through the browser canvas using fonts available on the device.

Practical Tips and Limitations

Preview the output before sharing. The visual appearance of non-Latin text depends on fonts available in your browser; page numbers use standard digits.

Frequently Asked Questions

Can I watermark selected pages only?

Yes. Enter a range such as 1-3,5. Leave the field blank to apply changes to all pages.

Can I add page numbers without a watermark?

Yes. Enable Add page numbers and leave the watermark text empty.

Are PDF files uploaded?

No. The document is modified locally in your browser using pdf-lib and canvas.
