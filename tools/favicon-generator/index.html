Favicon Generator

Generate common website favicon PNG sizes, a PNG-based ICO file and ready-to-use HTML icon tags from a PNG, JPEG or WebP image.

Open Favicon Generator

How to Use Favicon Generator

  1. Upload a PNG, JPEG or WebP image up to 10 MB.
  2. Choose a background color and adjust image padding.
  3. Generate and download the icon pack ZIP containing all icon sizes and an HTML snippet.

Key features

  • Creates PNG icons at 16, 32, 48, 180, 192 and 512 pixels.
  • Includes a 48×48 ICO file with embedded PNG image data.
  • Adjustable background color and image padding.
  • Provides HTML link tags for browser and Apple touch icons.

Frequently Asked Questions

Which image formats are supported?

PNG, JPEG and WebP images up to 10 MB are supported.

What is included in the download?

Six PNG sizes, a 48×48 ICO file and an HTML snippet are included in one ZIP archive.

Are images uploaded?

No. Image processing happens locally in your browser.

Which favicon sizes should a website provide?

Common browser icon sizes include 16×16 and 32×32 pixels, while Apple touch and modern app contexts may use larger PNG icons.

Where do I add the generated favicon HTML?

Place the generated link elements in the document head and upload the icon files to paths that match the references.

Helpful tips and limitations

Use a simple square source image with a clear subject. Check the generated icon at 16×16 pixels because small details may not remain visible.
