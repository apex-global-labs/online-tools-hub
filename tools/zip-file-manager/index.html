ZIP File Manager

Create ZIP archives or extract selected files from ZIP files. Processing stays in your browser with clear file and size limits.

Open ZIP File Manager

How to Use ZIP File Manager

  1. Choose up to 100 files and select Create ZIP to download an archive.
  2. Choose an existing ZIP file and select Inspect ZIP contents.
  3. Select the entries you want and download them together as a new ZIP archive.

Key features

  • Create ZIP archives from multiple files.
  • Inspect archive entries and select files to extract.
  • Local browser processing with no ToolNest upload endpoint.
  • Limits for file count, file size, archive size and expanded size.

Frequently Asked Questions

Does ZIP Manager upload my selected files?

No. ZIP creation and extraction happen in your browser. The ZIP library is loaded from a public CDN when needed.

Can I extract password-protected ZIP files?

No. Password-protected archives are not supported.

What are the file limits?

The tool limits source files to 100 items, 25 MB per file and 50 MB total, with a 50 MB archive limit and 50 MB expanded extraction limit.

Helpful tips and limitations

Only open archives from sources you trust. The tool blocks unsafe archive paths and limits the number and expanded size of entries.
