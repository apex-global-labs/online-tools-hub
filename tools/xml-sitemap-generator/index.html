XML Sitemap Generator

Build an XML sitemap from a list of public page URLs. This free browser-based generator validates HTTP and HTTPS addresses, removes duplicates and creates sitemap XML without sending your URL list to a server.

How to Use XML Sitemap Generator

  1. Paste one complete website URL per line into the input area.
  2. Select Generate XML sitemap to validate and normalize the addresses.
  3. Review the XML, then copy or download it as sitemap.xml.

Key Features

  • Accepts up to 500 absolute HTTP or HTTPS URLs.
  • Escapes XML characters and removes duplicate URLs.
  • Creates a standard sitemap XML document locally in your browser.

Frequently Asked Questions

What URLs should I include?

Include canonical, publicly accessible pages that you want search engines to discover. Avoid private, duplicate or redirected URLs.

Does this tool publish the sitemap?

No. It generates XML text for you to save and upload to your website.

How many URLs can I add?

This version accepts up to 500 URLs in one sitemap. Larger websites should use a sitemap workflow that can create sitemap indexes.
