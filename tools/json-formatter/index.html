Frequently Asked Questions

What does JSON validation check?

It checks whether the input follows JSON syntax, including quotes, commas, brackets and braces.

Does minifying JSON change its values?

No. Minifying removes unnecessary whitespace while preserving the parsed data values.

Why is my JSON invalid?

Common causes include single-quoted strings, trailing commas, unquoted property names or mismatched brackets.
