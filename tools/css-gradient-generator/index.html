Frequently Asked Questions

What is a CSS gradient?

A CSS gradient is a background generated by the browser from color transitions, without requiring an image file.

What is the difference between linear and radial gradients?

A linear gradient blends colors along a direction, while a radial gradient spreads colors outward from a center point.

Can I use the generated CSS in my website?

Yes. Copy the background declaration into a CSS rule and adjust it to match your design.
