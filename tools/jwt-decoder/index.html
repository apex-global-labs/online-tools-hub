JWT Decoder

Decode JWT header and payload locally without sending tokens to a server.

Open JWT Decoder

How to Use JWT Decoder

  1. Paste a three-part JWT into the input box.
  2. Select Decode JWT to read the header and payload.
  3. Review the optional expiration claim and copy the decoded result.

Key Features

  • Decodes Base64URL-encoded header and payload.
  • Displays a readable JSON result and expiration time when available.
  • Runs locally without sending the token or a secret to a server.

Frequently Asked Questions

Does this verify the JWT signature?

No. It only decodes the header and payload. A decoded token is not proof that its signature or claims are valid.

Is the token uploaded?

No. Decoding happens locally in your browser.

Should I paste a production access token?

Avoid sharing sensitive credentials. Treat tokens as secrets even when using a local decoder.

Helpful Tips and Limitations

Never trust claims until the token's signature and relevant claims have been verified by the intended application.
